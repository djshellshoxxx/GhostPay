# Test vectors

## scheme1.json

ERC-5564 scheme-1 vectors pinned by ADR-0001, with GhostPay metadata layouts.

- **Provenance:** generated by `node test-vectors/generate.mjs` (run from the repo root) using
  `@scopelift/stealth-address-sdk` 1.0.0-beta.5 (MIT, ScopeLift) from fixed **test-only** private keys.
  Library versions, Node version and generation date are recorded inside the file under `provenance` / `generatedAt`
  (generated 2026-10-21 with Node v22.22.0, `@noble/secp256k1` 2.3.0 (SDK dependency), `@noble/curves` 2.4.0, `viem` 2.57.7).
- **What comes from the SDK:** stealth address, ephemeral public key, view tag, stealth private key
  (`generateStealthAddress`, `checkStealthAddress`, `computeStealthKey`). The generator also asserts the SDK's own
  check accepts every vector.
- **What does not:** the 57-byte `metadata.erc20` / `metadata.native` strings are plain concatenations per
  `docs/CONTRACTS_SPEC.md` (the SDK has no metadata builder). The generator does not import `@ghostpay/core-crypto`,
  so expected values are never derived from the code under test.
- **Loading the SDK:** its ESM output uses extensionless imports that plain Node rejects, so the generator loads it
  through Vite's SSR loader (`vite` is a transitive dependency of `vitest`).
- **Consumers:** `packages/core-crypto/src/vectors.test.ts` asserts byte-for-byte equality for every vector
  (meta-address, address, ephemeral key, view tag, metadata, announcement check, stealth private key).
- **Keys:** the private keys in the file are public. Never use them for anything but tests.
- **Regenerating** changes only `generatedAt` unless a dependency changed; a diff in any other field means the
  SDK output changed and must be investigated, never "fixed" by editing the expected values.

Vector set: mid-range scalars, smallest scalars (1, 2, 3), largest scalars (n-1, n-2, n-3), half-width and n/2
boundary scalars, short scalars with many leading zero bytes, alternating bit patterns.

## policy-scheme.json

Scheme `0x47500002` (policy-guarded account) vectors for `@ghostpay/policy-scheme`.

- **Provenance:** `node test-vectors/generate-policy-scheme.mjs` (repo root). Owner EOA, ephemeral key, view tag and owner key come
  from `@scopelift/stealth-address-sdk` (scheme-1 maths, loaded through Vite like `generate.mjs`); `abi.encode`, keccak256,
  CREATE/CREATE2 addresses, EIP-712 digests and signatures from `viem`; the limits tree from a separate StandardMerkleTree
  re-implementation inside the generator. The package under test is never imported.
- **Contents:** deployment (chain 31337, factory/implementation as `CREATE(deployer, 1/0)` of a test key), the four type strings and
  typehashes, four limits trees with every proof, invalid trees with expected error codes, four accounts (keys, scheme-2 meta-address,
  policy, policy hash, salt, owner, account, owner key) and per account signed `Withdraw`/`CancelWithdraw`/`ProposeDestination`/`CancelDestination`.
- **Consumers:** `packages/policy-scheme/src/vectors.test.ts` (byte equality) and `src/anvil.test.ts`, which deploys the real contracts
  from the same key and checks the predicted addresses, typehashes, domain separators and that the vector signatures are accepted on-chain.
- **Keys:** public test keys only.

## tags.json

Feature 4 encrypted tag archive (`.gpa`, spec 08) vectors.

- **Provenance:** generated by `node test-vectors/generate-tag-archive.mjs` with `node:crypto` only (scrypt, AES-256-GCM) from the format documented in `apps/web/src/lib/tagArchive.ts`; the app code is never imported, so the consumer is a cross-implementation check. Node version and date are recorded in the file.
- **Coverage:** 5 valid archives (one record, empty, optional fields + unicode + history + mixed-case hex, NFKC passphrase normalisation NFC/NFD, production N=2^17) and 12 refusals (wrong passphrase, flipped ciphertext/tag/salt byte, AAD-bound `r` change, N outside 2^14..2^18, wrong magic, truncation, unknown key, newer version, invalid address).
- **Consumer:** `apps/web/src/lib/tagArchive.vectors.test.ts`.
- **Secrets:** passphrases, salts and IVs are public TEST-ONLY values. Regenerating changes only `generatedAt`/`node`; any other diff must be investigated.
