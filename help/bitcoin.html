Bitcoin Silent Payments

Silent Payments (BIP-352) is Bitcoin’s version of the one-time address idea: one static address, a fresh output for every payment.

EXPERIMENTAL GhostPay has a tested library for this. It is not wired into the web app or the relayer and has never run on a real network. Testnet only.

In plain words

  • The receiver has two keys: a scan key to find payments and a spend key to move them.
  • The sender combines its own input keys with the receiver’s address to make a new output key. No contact needed.
  • Nothing on-chain says it is a silent payment. There is no notification transaction.
  • Scanning needs data from every candidate transaction, which is heavier than the Ethereum view-tag scan.

Fees on Bitcoin

There is no enforceable GhostPay protocol fee on Bitcoin. Amounts are in satoshis.
