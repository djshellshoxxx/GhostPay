# Coverage sources and availability rules

Snapshot date is November 28, 2026. Popularity uses worldwide observed browser traffic for October 2026, the last complete month. The P0 device selections are representative choices. The sources do not provide GhostPay users' hardware distribution.

| Area | Evidence and interpretation |
|---|---|
| Browser demand | Chrome 68.79%, Safari 16.59%, Edge 5.36%, Firefox 2.57%, Opera 2.16% and Samsung Internet 2.05% worldwide. [Statcounter browsers](https://gs.statcounter.com/browser-market-share/all/worldwide/2026-10) |
| Mobile fleet | Apple, Samsung and Xiaomi lead the cited vendor traffic. OPPO and vivo extend the Android cohort. Pixel adds a reference Android implementation. [Statcounter mobile vendors](https://gs.statcounter.com/vendor-market-share/mobile/worldwide/2026-10) |
| Edge | Desktop 158.0.4370.45 and Extended Stable 156.0.4314.110 were documented November 25. The 157 line is historical. Windows 10 browser patches and OS servicing have separate lifecycles. Edge 109 is the last supported line on the named legacy Windows families. [Stable channel](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-relnote-stable-channel) · [Schedule and history](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-release-schedule) · [Platform support](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-supported-operating-systems) · [Lifecycle](https://learn.microsoft.com/en-us/lifecycle/products/microsoft-edge) · [Mobile schedule](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-mobile-release-schedule) |
| Chrome | Record the installed platform-specific patch. Chrome 109 is the final legacy Windows line. [Requirements](https://support.google.com/chrome/a/answer/7100626) · [Desktop 158 update](https://chromereleases.googleblog.com/2026/11/stable-channel-update-for-desktop_01734282054.html) |
| Apple | November 9 updates list iOS/iPadOS 27.2.1, 26.7.3 and specific 18.7.12 devices, plus macOS 27.2.1, 26.7.3 and 15.8.3. Hardware launch floors, App Store minima and availability of previously retained images can narrow rows. Safari on Windows ended at 5.1.7. Record the app, region and actual engine where independently known. [Releases](https://support.apple.com/en-us/100100) · [iPhone models](https://support.apple.com/en-us/108044) · [iPad models](https://support.apple.com/en-us/108043) · [Safari updates](https://support.apple.com/en-us/102665) · [Alternative browser engines](https://developer.apple.com/support/alternative-browser-engines/) |
| Android | The November bulletin lists Android 14, 15, 16 and 17 among updated AOSP versions. The actual OEM model, region and patch level determine the installed device state. Android 10–13 are additional compatibility lanes. [Platform/API mapping](https://developer.android.com/guide/topics/manifest/uses-sdk-element) · [November bulletin](https://source.android.com/docs/security/bulletin/2026/2026-11-01) |
| Firefox | Product Details lists desktop Firefox 161.0, ESR 153.8.0 and ESR 115.46.0. Mozilla lists 115 ESR for Windows 7/8/8.1. iOS has a separate app version. [Product Details](https://product-details.mozilla.org/1.0/firefox_versions.json) · [Legacy Windows support](https://support.mozilla.org/en-US/kb/firefox-users-windows-7-8-and-81-moving-extended-support) |
| Opera and Brave | The catalog uses each product's own numbering. Desktop Opera 95 was the final Win7/8-era line. Confirm server variants in the lab. [Opera 140](https://blogs.opera.com/desktop/2026/11/opera-140-stable/) · [Opera legacy downloads](https://www.opera.com/download) · [Brave releases](https://brave.com/latest/) |
| Chromebook | Native ChromeOS Chrome, an Android app installed through Google Play and a Linux container are separate environments. The last two depend on device and administrator support. [Android apps on Chromebook](https://support.google.com/chromebook/answer/7021273) |
| TV hardware | Fire OS, Vega OS and Google/Android TV have distinct devices and app stores. A store browser row requests discovery when availability is unknown. A cast screen does not establish a TV browser pass. [Amazon device/OS map](https://developer.amazon.com/docs/device-specs/identify-fire-tv-devices.html) |
| Native automation | Match Edge and WebDriver builds and read observed capabilities. A windows-2025 hosted runner uses Windows Server. [Edge WebDriver](https://learn.microsoft.com/en-us/microsoft-edge/webdriver/) · [Windows runner image](https://github.com/actions/runner-images/blob/main/images/windows/Windows2025-Readme.md) |
