# @ghostpay/core-crypto

ERC-5564 **scheme 1** stealth-address engine for GhostPay (secp256k1), pinned by ADR-0001:

```
S   = p_eph * P_view            (33-byte compressed point)
s_h = keccak256(S)              view tag = s_h[0]
h   = int(s_h) mod n            must be non-zero
Q   = P_spend + h*G             address = last 20 bytes of keccak256(Q.x || Q.y), EIP-55
p   = (p_spend + h) mod n       must be non-zero, and is re-mapped to the announced address before use
```

Matches `@scopelift/stealth-address-sdk@1.0.0-beta.5` (dev dependency, used only by differential tests, never imported by `src`).

## Usage

```ts
import {
  generateKeySet, encodeMetaAddress, deriveStealthPayment,
  checkAnnouncement, deriveStealthSecret, buildErc20Metadata, parseMetadata,
} from '@ghostpay/core-crypto';

const keys = generateKeySet();                       // recipient
const meta = encodeMetaAddress(keys);                // st:eth:0x<spendPub><viewPub>

const pay = deriveStealthPayment(meta);              // sender
const metadata = buildErc20Metadata(pay.viewTag, tokenAddress, netAmount); // 57 bytes

const ann = { stealthAddress: pay.stealthAddress,    // scanner (hex fields from the Announcement event)
              ephemeralPublicKey: '0x' + hex(pay.ephemeralPublicKey), metadata: '0x' + hex(metadata) };
const hit = checkAnnouncement(ann, keys.viewingSecret, keys.spendingPublicKey);
if (hit.matches) {
  const secret = deriveStealthSecret(ann, keys);     // verified against the announced address
}
```

Production code passes no `rng`; tests inject a deterministic `RandomSource`.

## Security notes

- Secrets (`SecretScalar`) are `Uint8Array` subclasses that **throw** on `JSON.stringify`, `String()`,
  template strings, `util.inspect` and `console.log`. `unsafeRevealSecret` returns a plain copy for explicit export boundaries.
  `structuredClone`/`postMessage` of a secret copies raw bytes (as a plain `Uint8Array`): never send secrets to workers or storage.
- **JavaScript cannot guarantee zeroization.** `zeroize()` overwrites buffers on a best-effort basis; the JIT, GC and
  structured clone may leave copies. Do not rely on it as a security boundary.
- Randomness: `crypto.getRandomValues` with rejection sampling (no modular bias). `Math.random` is banned by ESLint.
- Errors are fixed strings with a stable `code`; they never contain key bytes or the offending input.
- `checkAnnouncement` returns `{ matches: false }` on malformed log data so a hostile log cannot stop a scanner.
- The 1-byte view tag leaks one byte of hash of the shared secret by design; it does not hide payer, amount, time or graph.
- Coverage thresholds and tests establish regression safety, not cryptographic correctness. This package has had no external audit.
