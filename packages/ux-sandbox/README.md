# @ghostpay/ux-sandbox

Deprecated: use @ghostpay/sandbox; thin re-export kept for compatibility.

All former functionality now lives in `@ghostpay/sandbox` (`src/ux/`). Colliding names are exported there with a `Ux` prefix (`UxMockChain`, `UxSandboxError`, `UxClock`, `UxSandboxErrorCode`); this package maps them back to the old names.
