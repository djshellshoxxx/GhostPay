# @ghostpay/policy-scheme

Client side of the policy-guarded stealth account, ERC-5564 scheme id `0x47500002`
(`docs/CONTRACTS_SPEC.md` section 4, `packages/contracts/DEVIATIONS.md` P1-P19, A2).
**Experimental (ADR-0014): not enabled in the app or the relayer.**

| Module | What it does |
| --- | --- |
| `policy.ts` | `computePolicyHash` (`keccak256(abi.encode(destination, delaySeconds, limitsRoot))`), `validatePolicy` (factory rules), `accountSalt`, `cloneInitCodeHash`, `predictAccountAddress` (OpenZeppelin `Clones` CREATE2 formula) |
| `limits.ts` | per-token limits tree: `limitLeafHash` (OZ double-hashed leaf), `buildLimitsTree` (StandardMerkleTree layout, sorted pairs; refuses duplicate tokens), `getLimitProof`, `verifyLimitProof`, `noLimitsProof` |
| `meta.ts` | scheme-2 meta-address `st:eth:gp2:0x<spend33><view33><policyHash32>` |
| `derive.ts` | sender `deriveScheme2Payment` (owner via core-crypto scheme-1 maths, account via CREATE2), scanner `checkScheme2Announcement`, `deriveScheme2OwnerKey` |
| `eip712.ts` | `Withdraw` (with `limitLeafHash`), `CancelWithdraw`, `ProposeDestination`, `CancelDestination` typed data, ids, digests; `signPolicyTypedData` |
| `calldata.ts` | factory `deploy` and every `PolicyAccount` call |
| `router.ts` | `GhostPayPolicyRouter` `payERC20` / `payERC20WithPermit` / `payNative` / `payERC20WithBuffer` calldata and decoder |

No new crypto libraries: `@noble/curves`, `@noble/hashes`, `viem` and `@ghostpay/core-crypto`, pinned exactly as in core-crypto.

## Tests

`npm test -w @ghostpay/policy-scheme` (vitest, coverage thresholds 95/90/95/95).

- `vectors.test.ts`: `test-vectors/policy-scheme.json` (generated by `test-vectors/generate-policy-scheme.mjs` from
  the ScopeLift SDK and viem, never from this package).
- `properties.test.ts`: fast-check properties of the tree, differential checks against core-crypto and viem `getContractAddress`.
- `anvil.test.ts`: deploys the real `PolicyAccount`, `PolicyAccountFactory`, `GhostPayPolicyRouter`, announcer and a mock token
  on a local anvil and checks addresses, typehashes, domain separators, vector signatures, withdraw/cancel/destination flows
  and a router payment -> scan -> deploy -> withdraw round trip. Needs `anvil` (or `ANVIL_BIN`) and forge artifacts in
  `packages/contracts/out` (override with `POLICY_SCHEME_ARTIFACTS`, a path relative to `src/`). Skips when missing,
  **fails** when `REQUIRE_ANVIL=1`.

`npm run gen-abi` regenerates `src/abi/*.ts` from forge output; `npm run gen-vectors` regenerates the vectors.
