# GhostPay branch and PR retirement plan — 2026-11-18

**Nothing is deleted, closed or archived now.** This is a proposed mapping for Phase E of the gameplan. Every retirement action below requires the owner's final approval, given after the candidate is qualified and promoted through the normal protected review.

Source data: `branch_census_20261118.json` (215 refs, pinned candidate `278c9a2734a56c548a75acd1c2a4eab7397d62d1`, unified `beb525dddcca103de9eda447b55cddf7ee2f428c`). Patch equivalence is not proof of current behavior: each retirement keeps the outstanding acceptance work listed here open until the candidate's own tests and acceptance evidence cover it.

## Preconditions for any retirement

1. The candidate is qualified (Checkpoint A, then B for promotion) and promoted to `main` through protected review.
2. A fresh census confirms that the head SHA of every ref to retire is unchanged from this plan. Any moved ref is re-dispositioned first.
3. Preservation exists for every non-ancestor head. A ref that is not an ancestor of the promoted source keeps its commits reachable only through the branch, or through `refs/pull/<n>/head` if it has a PR. Before deleting such a branch, the owner chooses a preservation mechanism, for example an annotated `archive/<branch>` tag or a git bundle with a checksum. This plan proposes it but does not create it.
4. Each closed PR receives a comment naming the retained source commit(s)/paths and this plan's entry. These are GitHub writes, performed only after approval and not by this lane.
5. Outstanding acceptance listed for an entry is either complete or moved to a tracked task before the entry is retired.
