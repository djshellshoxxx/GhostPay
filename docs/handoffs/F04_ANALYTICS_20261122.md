## Implemented behavior

`summarizeDashboardProjection(projection, asOfSeconds, context)` consumes a **trusted in-memory** F04 `DashboardProjection`, not a user-imported file. It does **not** verify chain settlement, signed invoices or scan completeness.

The function produces an immutable `ghostpay.dashboard-analytics/1` summary grouped strictly by chain and asset, with exact atomic string totals for expected invoice amounts and separately provider-final on-time, pending and late-final evidence. It counts invoice status categories, outstanding vs expired-unsettled balances using an explicit seconds clock, partially paid, late, and review-required invoices. It retains `coverage: not-evaluated`; no conversion to fiat, unified asset total, historic fee inference or certainty about unswept history is attempted.

Input guards reject invalid schema/coverage, duplicate invoice references, missing/getter-backed/sparse rows, malformed atomic-unit values, inconsistent projection totals, and expired/locked/revision-invalid contexts. At the invoice deadline, insufficient on-time final evidence becomes expired-unsettled; a final event at/after deadline does not become an on-time payment. Past final evidence removed by a reorg disappears when the source projection is rebuilt. Summary code never calls RPC, requests downloads, touches storage, or logs sensitive data.

**Important labels:** `finalAtomic` means the sum of amounts that the *caller-provided trusted F04 projection* classified as canonical provider-final and on time. It is not a statement that all payments have been found. `expiredUnsettledInvoices` means incomplete *in the available evidence*, not an independently proven absence of payment.
