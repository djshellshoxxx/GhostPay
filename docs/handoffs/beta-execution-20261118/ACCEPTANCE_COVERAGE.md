## Network and final-candidate boundaries

Recovery evidence applies to **EVM ERC-5564 scheme 1**. Local sweep models cover native currency and supported ERC-20 cases separately, but the raw-key independent spend is a local Anvil native transfer. It does not certify every EVM network/token or substitute for approved testnet deployments and wallet acceptance. The clean Pages artifacts recorded in the report had payments disabled on every chain.

Bitcoin, Solana, TRON, policy accounts, ERC-4337 and EIP-7702 recovery are not certified by this work. Full-profile or experimental source presence is not lean Pages acceptance; unsupported recovery schemes must remain refused. The existing optional EVM relayer path is reachable from core Sweep, but no relayer infrastructure or service acceptance was added.

Both original #222 hosted browser runs remain red. The separate [Pages job](https://github.com/djshellshoxxx/GhostPay/actions/runs/44279444265/job/134715947261) reported **11 passed, 2 failed, 3 dependent tests unrun** on the same synthetic merge as B. B's first journey passed receipt signature verification, then failed its obsolete address expectation before payer receipt import, direct sweep or dust-resweep checks. #233 addresses the observed fixture assumptions in source; no successful repaired-head browser rerun is asserted.

The eventual combined candidate requires exact-head automated gates, independent integrated-source review, the outstanding browser/device/recovery/egress scenarios above, and a source-matched static artifact. These records qualify neither a beta release nor production deployment.
