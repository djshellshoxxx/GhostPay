### F4 (info): budget-held scan checkpoint uses the reported head
- apps/web/src/lib/scanClient.ts:567 (a5 19c7e2d/d9fe8b4): when the cursor is at least `finalityDepth` below `pageHead`, the checkpoint skips the replay tail. `pageHead` is the lower of the two providers' heads.
- With a second provider, the saved page-end anchor is re-corroborated with three reads (`corroborateAnchor`). Any mismatch is a discrepancy and the checkpoint is withheld, so this is fail-closed.
- With a single provider, the primary's head is trusted. The primary is already trusted for the logs in that mode.
- Pending matches below the edge pull the checkpoint back. Router blocks at or above a reorg's rolledBackTo are dropped, so the privacy set counts each block once.
- No change needed.
