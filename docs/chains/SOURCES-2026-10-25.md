Why the rest is empty:
- Heartbeat: only `docs.chain.link` / `data.chain.link` publish it and neither was reachable. The `3600` in `chainlink-agent-skills/.../PriceFeedConsumer.s.sol` is a template staleness threshold, not a heartbeat, so it is not used. The registry field `heartbeatSec` is therefore absent and the payer's staleness limit is the invoice quote TTL (`pay.ts`, 60 s to 24 h). This is weaker than a heartbeat-derived limit; fill `heartbeatSec` and clamp `maxAgeSeconds` once the docs page can be read.
- Base Sepolia ETH / USD: `0x4aDC67696bA383F43DD60A9e78F2C97Fbbfc7cb1` appears in `smartcontractkit/documentation` `src/content/cre-templates/x402-price-alerts.mdx` without a network label, and as Base Sepolia only in third-party repos (Aave address book, Hyperbridge). Neither is an authoritative network label, so it is NOT used.
- USDC / USD (`0xA2F78ab2355fe2f984D808B5CeE7FD0A93D5270E` for Sepolia) appears only in third-party repos (OpenZeppelin docs, others). Not used.
- L2 sequencer uptime feed (spec 03): not sourced, not implemented.
