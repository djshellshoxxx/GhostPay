# Spec: accounting & tax export (@ghostpay/merchant-ledger)

## Requirements
- R1 Formats: CSV (generic), JSON (sorted keys, amounts as strings), Xero-style invoice CSV, QuickBooks-IIF-like (optional, TRNS/SPL/ENDTRNS).
- R2 Amounts: bigint minor -> decimal string using currency exponent (default 2; JPY/KRW 0; BHD/KWD/JOD 3; override allowed). Negative handled.
- R3 Tax: `computeTax(subtotal, rateBps, mode)`, modes half-up, half-even, down, up; integer arithmetic only. Round-trip with exact bps.
- R4 Per-period tax summary (month/quarter/year, UTC) grouped by period, currency, rate: count, taxable base, tax.
- R5 CSV safety: RFC4180 quoting; text cells starting with `= + - @ TAB CR` get a leading `'` (formula injection); control chars stripped; numeric cells generated by us are not prefixed.
- R6 IIF safety: tabs/newlines in text replaced by space.
- R7 Deterministic ordering: (date, id) codepoint; same input in any order -> identical bytes. CRLF line endings for CSV.
- R8 Invalid money/rates throw `LedgerError`.

## Acceptance tests
decimal format cases (0, 5, 100, -5, exp 0, exp 3); rounding vectors (0.5 half-even etc.); `=cmd|' /C calc'!A0` customer escaped; quotes/commas/newlines; ordering independence; period boundaries (Dec 31 23:59:59 vs Jan 1); quarter; each export golden string; huge amounts.
