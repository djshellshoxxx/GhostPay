Announcement
A public log entry saying a payment was made: one-time address, ephemeral public key, view tag. It lets the seller find the payment.
Anonymity set
The crowd you blend into. Here, mostly “GhostPay users on that chain”, which is small and listable.
Base units
The smallest unit of a token (for USDC, millionths). Fees are computed on them.
Basis point (bps)
One hundredth of a percent. 25 bps is 0.25 %.
Bearer link
A link that works for anyone who holds it. The invoice link is one.
BIP-352 / Silent Payments
Bitcoin scheme with one static address and a fresh output per payment.
Deployment manifest
A file naming the contract and fee-recipient addresses for a chain. Without one the app disables payment.
Destination
The wallet you sweep to. Use a fresh one.
Ephemeral key
A one-off key pair the payer makes for each payment. Only its public half is published.
ERC-2612 permit
A signed message that lets a contract move tokens without a separate approval transaction.
ERC-5564
The Ethereum standard for stealth addresses and announcements.
Gas
The network fee for a transaction, paid in the chain’s native coin.
Gas buffer
Extra native coin a payer adds to the one-time address so the seller can pay gas. Public; links payer and address.
Meta-address
The public address a seller shares. Holds a spending public key and a viewing public key.
Nonce
A number used once. In a sweep order it stops replays.
One-time address
A fresh address made for a single payment, also called a stealth address.
Policy account
Experimental contract with a fixed destination, delay and limits.
PayJoin
Bitcoin technique where the receiver adds an input to the payment. Planned, not built.
Relayer
A service that submits your signed sweep and pays gas for a fee.
Router
GhostPay’s checkout contract: takes the 0.25 % fee, forwards the rest, posts the announcement.
RPC
The server your app asks to read the chain and send transactions.
Spending key
The private key that can move funds. Never share.
Sweep
Moving funds from a one-time address to your wallet.
Testnet
A practice network with valueless coins. GhostPay is testnet-only today.
Timelock / delay
A required wait before a withdrawal can happen.
View tag
The first byte of a hash of the shared secret. A quick filter for the scanner; hides nothing.
Viewing key
The private key that lets software find your payments. Cannot spend, but reveals your history.
