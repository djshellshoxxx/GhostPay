# Security and supporting modules GhostPay still needs

Date: 2026-10-21. Branch `claude/remote-extensions-1`. Written from the repository as it stood at commit `ce9996b` plus the documents listed below; no code outside `packages/secret-box` and `packages/relayer-guard` was changed.

Read for this list: `README.md`, `SECURITY.md`, `docs/MASTER_BLUEPRINT.md`, `docs/POST_LAUNCH_FEATURES_SECURITY_ROADMAP.md`, `docs/SECURITY_QA_DEVOPS_PLAYBOOK.md`, `docs/APP_AND_RELAYER_SPEC.md`, `docs/threat-model/THREAT_MODEL.md`, `docs/audits/00..04`, `docs/remote/audits/*` (haiku reports, **unverified**: marked "(haiku)" where cited), every `packages/*/DEVIATIONS.md`, `docs/operators/relayer-runbook.md`, `.github/workflows/*`, `scripts/*` (names only), and the source files named in the evidence column.

Status vocabulary: **Exists** (code or doc in the tree that does the job, residual gaps named), **Partial** (some of it exists), **In progress elsewhere** (the README, threat model or runbook says another contributor is changing it; not verified here), **Missing**.

## Ranking rule

Rank = (harm if absent, from the threat model's asset order and the audit severities) x (how soon the gap is hit: before testnet > before mainnet > later) / (how much of it already exists). Items whose fix lives inside an existing package or app that this task may not edit are still ranked, but are not picked for a new standalone package.

## Why ranks 2 and 3 were implemented and 1, 4, 5 were not

- Rank 1 lives in `chain-adapters` and `apps/web`, which this task may not edit, and is being changed by another contributor.
- Ranks 2 and 3 are self-contained, need no new dependency (Node built-ins only), and close concrete open audit findings with tests. Neither package is wired into `apps/relayer`, `apps/web` or `core-crypto` yet; wiring is listed as follow-up in each spec.
- Ranks 4 and 5 need `viem` ABI decoding or Unicode data tables; their specs are written so they can be built next.
