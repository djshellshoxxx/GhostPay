# Source reuse decisions

Research performed before new feature implementation. No external source copied or new dependency introduced.

- **viem 2.57.19 / MIT:** already installed and pinned; reuse address utilities. Commit `3764f338a3474adafd639c98f2bbfa713bad95cb`: [getAddress](https://github.com/wevm/viem/blob/3764f338a3474adafd639c98f2bbfa713bad95cb/src/utils/address/getAddress.ts), [license](https://github.com/wevm/viem/blob/3764f338a3474adafd639c98f2bbfa713bad95cb/src/LICENSE). Preserve strict existing input validation; normalization alone does not validate a mixed-case checksum.
- **KeeWeb / MIT:** reviewed clipboard source `ad7891de92cf666400a6b4c859eeb731b0f68761`, [code](https://github.com/keeweb/keeweb/blob/ad7891de92cf666400a6b4c859eeb731b0f68761/app/scripts/comp/browser/copy-paste.js), [license](https://github.com/keeweb/keeweb/blob/ad7891de92cf666400a6b4c859eeb731b0f68761/LICENSE). Desktop Launcher/Electron behavior and plaintext timer closure do not fit. Reuse GhostPay digest ownership instead.
- **idb-keyval / Apache-2.0:** reference `17a69a1165bef486d88950cb47d3913744f038ac`, [code](https://github.com/jakearchibald/idb-keyval/blob/17a69a1165bef486d88950cb47d3913744f038ac/src/index.ts), [license](https://github.com/jakearchibald/idb-keyval/blob/17a69a1165bef486d88950cb47d3913744f038ac/LICENCE). Atomic update reference only; generic clear/delMany cannot protect GhostPay recovery/pending/security data. Reuse existing domain CAS where applicable.
- **Cloudflare Kumo / MIT:** reference `eb12be53992be2aac1e0aca79b0545c9953751ba`, [sensitive input](https://github.com/cloudflare/kumo/blob/eb12be53992be2aac1e0aca79b0545c9953751ba/packages/kumo/src/components/sensitive-input/sensitive-input.tsx), [license](https://github.com/cloudflare/kumo/blob/eb12be53992be2aac1e0aca79b0545c9953751ba/LICENSE). Retains real input value and adds unrelated UI dependencies; use GhostPay hidden/inert presentation boundaries instead.
- Wallet lifecycle/disclosure: [EIP-1193](https://eips.ethereum.org/EIPS/eip-1193) plus existing wallet/session guards. No third-party wallet can supply GhostPay sole-copy preservation policy.
- Invoice minimization: existing invoice-schema canonical/signature/fragment codecs; write unsigned-data transformer. [BOLT12](https://github.com/lightning/bolts/blob/master/12-offer-encoding.md) is an incompatible protocol, not source to copy.

Browser clipboard compare/read/write is best effort, not atomic. Masking protects visible presentation, not same-origin script access. Missing local reuse history cannot prove global freshness. New copies would require original notices and compatibility review.
