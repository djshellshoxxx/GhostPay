# Library and contract QA

**Status:** package QA completed for the assigned in-scope Vitest packages; bounded stress and integration gaps remain. This is a test report, not a production-readiness signoff.

## Scope and method

Ran coverage-enabled `npm test -- --maxWorkers=1 --pool=threads` sequentially in 32 library packages. `chain-adapters`, `core-crypto`, and `invoice-schema` were covered by the coordinating QA; application tests were assigned to other QA runs. The working tree was shared with concurrent fix and build work, so the adapter type-drift failures below describe this run's baseline; the coordinator subsequently reports fixing those types and rerunning Solana's full suite successfully. Logs are in `/tmp/ghostpay-qa/` for the current session.

Packages with a clean baseline exit (27): `address-safety`, `amount-blur`, `btc-payjoin`, `btc-silent-payments`, `confidential-amounts`, `external-pools`, `external-pools-railgun`, `hops`, `hygiene`, `merchant-hooks`, `metadata-hardening`, `net-harness`, `net-transport`, `ops-monitor`, `payer-sponsor`, `payment-uri`, `pir-two-server`, `policy-scheme`, `pool-prover`, `pool-relayer`, `pool-sdk`, `privacy-pipeline`, `qr-exchange`, `relayer-guard`, `scan-source`, `secret-box`, and `tx-review`. Coverage thresholds passed for each package whose run completed successfully.

## Integration and smart-contract suites

- `btc-payjoin`'s separate regtest end-to-end suite was invoked. It reported one test file / four tests skipped because `BITCOIND_BIN` was unset or missing; the test explicitly documents that requirement. No regtest pass is claimed.
- `confidential-contracts` compiled 36 Solidity files using the verified `solc-0.8.28`. With `ANVIL_BIN` set, the quick Hardhat profile passed all nine chain-guard cases, the boundary fee split test, 100 randomized amount/balance cases, both 40-step randomized multi-actor conservation sequences, the HCU/gas case, and the router tests printed before the 180-second process cap. The profile did not complete: it reached `flushFees` when terminated (`/tmp/ghostpay-qa/confidential-contracts-quick.log`). The default suite was also bounded at 300 seconds and remained in the 1,000-run random-amount test after passing the chain guard and fee-boundary test (`/tmp/ghostpay-qa/confidential-contracts.log`). Thus the Solidity build and named tests passed, but no full Hardhat-suite pass is claimed. The package offers `test:quick` (`FUZZ_RUNS=100 INV_SEQUENCES=2`); its full router test tail remains expensive in this environment.
- `payer-hiding-contracts` Foundry suite passed after the repository's documented `scripts/fetch-entrypoint.sh` fetched test-only `@account-abstraction/contracts@0.7.0` under the gitignored `.vendor/` directory. `FOUNDRY_SOLC=/tmp/ghostpay-tools/solc-0.8.28 forge test --threads 1`: 7 suites, **108 passed, 0 failed, 0 skipped** in 204.25 seconds. This included the 10,000-run fuzz tests, default 256-run / depth-50 invariants (12,800 calls each), EIP-4337 v0.7 golden-vector checks, and independent review regressions. Initial missing-import failure and the successful full run are recorded at `/tmp/ghostpay-qa/payer-hiding-contracts.log`; the excluded-import diagnostic run was 74 passed / 0 failed before fetching the dependency.
- `contracts` default-fuzz Foundry suite: **409 passed, 0 failed, 0 skipped** across 26 suites in 828.83 seconds; all Foundry fuzz tests used their default 10,000 runs. Log: `/tmp/ghostpay-qa/contracts-after-fixes-default.log`. The earlier 400-run diagnostic's only failure was a stale audit assertion that pending withdrawals followed a changed destination; it now asserts rejection and cancel/re-request recovery. The final independent Factory run passed **32/32** after adding exact payer-debit checks, including true-return no-debit and wrong-debit adversarial tokens (`/tmp/ghostpay-qa/contracts-factory-final.log`). A subsequent full `forge snapshot --check` against the latest source ran **411 tests with 0 test failures/skips**, but exited 1 because the tracked gas snapshot was stale and included nondeterministic fuzz/invariant gas means. The repository now regenerates and checks snapshots with `--no-match-test 'testFuzz|invariant'`, matching the documented deterministic-snapshot policy; that CI-equivalent check passed **370/370** tests (`/tmp/ghostpay-qa/contracts-snapshot-check.log`). The focused changed account/audit tests passed 3/3 each, and final `forge fmt --check` plus `scripts/check-natspec.sh` passed. The ABI generator and required policy-scheme Anvil cross-check also passed after regeneration: 7/7 tests. This records the test snapshots honestly rather than presenting them as one atomic run.

The package tests include meaningful property/stress coverage already: BTC PayJoin property tests, privacy-profiles PP-10–PP-13 fast-check properties plus the 1,440-case deterministic PP-10 grid, pool-circuits witness/proof/forgery checks, and confidential-contracts fee fuzz and conservation sequences. The grid and Solidity suite limits above are real completion blockers for a clean full-suite claim, not skipped passes.

## Summary

This run confirms broad coverage across 32 packages and full coverage-threshold passes for 27 completed baseline packages, plus two forks-based recovery passes, the subsequently fixed privacy-profiles suite, the separate complete payer-hiding Foundry suite, the full 10,000-run contracts baseline, and focused latest Factory / policy-scheme integration checks. The remaining gaps are confidential-contracts full-suite completion, an unverified Tron adapter rerun, and lack of a Bitcoin regtest daemon. `solana-stealth`'s reported drift fix is coordinator-confirmed, not independently re-run here. These results do not establish production readiness or substitute for contract security review, live testnet deployment, or provider-backed integration testing.
