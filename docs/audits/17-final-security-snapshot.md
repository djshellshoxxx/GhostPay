# Final security snapshot for the consolidation worktree

**Review date:** 2026-10-22  
**Target:** current shared worktree for `integration/consolidated-2026-10-21` (uncommitted integration state).  
**Purpose:** disposition of every Critical/High/Medium candidate in [`05-full-audit.md`](05-full-audit.md), with additional defects found during the migration delta review. This is a focused internal review, not an external audit or a launch certification.

## Audit 05 findings

The table records whether the old trigger still applies to the current tree. “Closed” means the specific reported defect has a current fix and relevant regression evidence; it does not mean the whole package, deployment, or trust model is certified. Evidence is named narrowly so a test of one property is not mistaken for broader assurance.

## Validation and review limits

Focused verification for this snapshot: after rebuilding the chain-adapter workspace so web tests resolve current `dist`, the web scan client, scanner core, and Scan view suites passed 54 tests; chain-adapter payment verification passed 24 tests. These include whole-run cap, stop-on-discrepancy, replay, deep-reorg/finality-tail, and transaction-hash receipt regressions. Targeted ESLint for `scanClient.ts`, its tests, `Scan.tsx`, and the Bitcoin provider disclosure passed; web and chain-adapter typechecks passed. The repository's full web baseline passed 17 Playwright tests before the latest release-gate and scan changes; no fresh full E2E run is claimed. No full test suite, external audit, live-chain deployment, real RPC-provider attack exercise, production wallet signing, or production relayer run is claimed by this snapshot. Test fixtures establish local properties only. The final worktree is evolving and this document must be refreshed against the committed release candidate before any deployment decision.

The remaining unresolved medium findings are the intentional data disclosure to Bitcoin/EVM scan providers. The privacy-related code makes those disclosures more explicit; it does not make them unlinkable. The app remains undeployed and must not be used with real funds.
