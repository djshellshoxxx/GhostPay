## Coordination

- File ownership per worker keeps waves conflict-free; hot files are `Pay.tsx` (1, then 10), `Scan.tsx` (2, then 5),
  `App.tsx` (3, 6: one route line each), locales (wave 3 only).
- Each worker runs in its own git worktree on `worker/<id>`, commits small, never pushes. The integrator merges each
  finished branch into the base right away, runs the broad checks once per wave, and pushes. Later workers start from
  the merged base, so nothing is redone.
- At most five workers run at once (4 CPUs). Workers run only scoped tests; the integrator runs the full suite.
- Token budget: workers read only their spec and owned files, and report in under 150 words.
